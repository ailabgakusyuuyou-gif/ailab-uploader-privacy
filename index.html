AILab 動画アップロードツール　プライバシーポリシー

就労継続支援B型事業所 AILab（アイラボ）（以下「当事業所」）は、当事業所が運営するYouTubeチャンネルへ動画を投稿するための社内ツール「YouTube-Upload」（以下「本ツール」）について、次のとおり個人情報を取り扱います。

1. 本ツールの目的

本ツールは、当事業所が制作した動画を、当事業所が管理するYouTubeチャンネルへアップロードするためだけに使います。当事業所のスタッフ以外は利用しません。

2. 取得する情報

Googleアカウントでの認証を通じて、次の情報を取得します。

  • YouTubeへの動画アップロード権限
  • 投稿先チャンネルを確かめるための、チャンネル名とチャンネルID
  • 認証したGoogleアカウントの名前とメールアドレス

3. 情報の使い方

取得した情報は、動画のアップロードと投稿先チャンネルの確認にだけ使います。広告、分析、ほかの目的には使いません。

4. 保存と管理

認証情報（トークン）は、当事業所が管理するパソコンの中にだけ保存します。外部のサーバーには送りません。

5. 第三者への提供

法令にもとづく場合をのぞき、取得した情報を第三者に提供しません。

6. Google APIサービスの利用について

本ツールがGoogle APIから受け取った情報の使い方は、Google API Services User Data Policy（限定使用の要件を含む）にしたがいます。

7. 許可の取り消し

Googleアカウントの「サードパーティのアクセス」の設定から、いつでも本ツールへの許可を取り消せます。
